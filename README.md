# 秘林倖存者 / Hollow Grove Survivor

以 Unity 開發的 2D 倖存者遊戲。在敵人包圍中移動求生，透過升級搭配武器、被動能力與技能，挑戰精英與 Boss，撐過十分鐘取得勝利。

## 遊戲特色

- **多樣成長組合**：五種武器、五種被動能力與兩種技能，透過升級選擇搭配戰鬥方式。
- **生存挑戰**：面對敵群、精英與 Boss，以十分鐘生存為目標。
- **永久強化**：搭配存檔系統，保留局外成長進度。
- **雙語介面**：支援繁體中文與英文。

## 遊玩方式

使用上述 Unity 版本開啟專案，載入 `Assets/Scenes/MainMenu.unity`，進入 Play Mode 即可遊玩。

| 操作 | 按鍵 |
| --- | --- |
| 移動 | WASD |
| 暫停 | ESC |
| 選擇升級 | 滑鼠或 1／2／3 |
