# 機敏資料保護規則

2026-11-03新增，依使用者明確要求。根目錄AGENTS.md為所有代理的強制行為規則，適用對話、工具輸出、截圖、檔案、報告與Git。

禁止出現真實token、API key、帳號登入資料、密碼、cookie、私鑰、授權憑證及機器驗證參數。範例僅用`<REDACTED>`、`YOUR_API_KEY`等佔位符；遊戲內非認證用途的物件識別碼不屬憑證。

所有文件與程式碼皆適用，包含範例、註解、測試資料、設定與產生的檔案；即使尚未加入Git也一樣。寫入或顯示前先檢查，測試僅用合成資料，認證透過憑證管理工具引用。

資料讀取前先縮小欄位，程序查詢僅取名稱、PID及執行檔路徑；日誌在本機過濾／遮蔽後才能輸出。不能先讀出值再在回覆中遮蔽，也不能用編碼、片段、摘要或截圖繞過。所有命中只回報路徑、數量與規則類型。

## Git 提交保護

以`pwsh -NoProfile -File Tools/Security/Install-GitHooks.ps1`安裝此clone的pre-commit。安裝器遇到既有自訂hook會停止，不覆蓋Git LFS或其他hooks；新clone仍須安裝。手動檢查：`pwsh -NoProfile -File Tools/Security/Check-Secrets.ps1 -Staged`。

檢查實際暫存區的新增／修改檔案與本機LFS內容，攔截已知金鑰／JWT／Bearer／私鑰格式、認證欄位字串值、URL內嵌憑證、敏感檔名與登入欄位。無法取得LFS內容或檢查失敗也拒絕提交；不會為掃描下載遠端內容。輸出不包含命中行或值。修正方式為移除值、改用佔位符或取消暫存；禁止以`--no-verify`、hooks覆寫或放行清單繞過。

此為本機防護，格式掃描不能保證找到所有機敏資訊，也無法判斷一般圖片內的文字；截圖、未知格式及提交訊息仍須人工／代理事前檢查。現有提交已檢查已知Unity欄位與常見格式，未發現命中；依使用者指示不改寫既有歷史。未新增遠端push或服務端政策。

完整本機可達歷史複查：`pwsh -NoProfile -File Tools/Security/Check-Secrets.ps1 -History`。檢查所有本機refs可達commit的檔案版本、提交訊息與可用的本機LFS內容，重複檔案版本只掃一次；不連線取得遠端資料，不涵蓋不可達物件或reflog。

## 已發生事件與處置邊界

M0曾因完整程序命令列查詢，將Unity認證與授權參數帶入聊天工具輸出；不保存值或該原始命令列於本文件。已傳給處理聊天的服務，不能認定完全留在本機；沒有公開散布或被他人取得的證據，也不能保證無外流。刪除本機內容或封存聊天不能撤回已傳送內容。

如再遇疑似機敏值，停止相關讀取／提交，只回報位置與類型。帳號撤銷／輪替、刪除聊天或改寫Git歷史須先取得明確授權；不要要求使用者貼入密碼或token。既有專案程式不因刪除聊天而需要重建，進度以Git與Documentation接續。
