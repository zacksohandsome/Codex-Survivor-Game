# GAME_DESIGN.md

# 遊戲設計規格

## 1. 遊戲基本資訊

| 項目 | 規格 |
|---|---|
| 遊戲類型 | 2D 俯視角 Survivor-like |
| 遊戲題材 | 奇幻冒險 |
| 遊戲平台 | Windows PC |
| 操作方式 | 鍵盤與滑鼠 |
| 遊戲模式 | 單場生存 |
| 單場時間 | 10 分鐘 |
| 玩家角色 | 固定職業、單一角色 |
| 勝利條件 | 存活至 10 分鐘結束 |
| 失敗條件 | 玩家生命值歸零 |
| 遊戲視角 | 俯視角、鏡頭跟隨玩家 |

## 2. 核心遊戲循環

### 2.1 單場流程

1. 從主選單進入武器選擇畫面。
2. 玩家選擇一把初始武器。
3. 開始遊戲，玩家出現在競技場中央。
4. 經過短暫開場倒數後，開始 10 分鐘計時。
5. 敵人從競技場邊緣生成並朝玩家移動。
6. 玩家透過 WASD 移動閃避，角色自動攻擊。
7. 擊殺敵人取得經驗寶石與隨機貨幣。
8. 經驗累積達標時暫停遊戲，提供三個升級選項。
9. 玩家逐步取得武器、被動能力、特殊技能與基礎屬性強化。
10. 難度隨時間增加，並於指定時間出現精英與 Boss。
11. 玩家死亡或存活 10 分鐘後結束本場。
12. 進入結算畫面，保存本場貨幣與統計。
13. 回到主選單，使用貨幣購買局外強化。

### 2.2 核心體驗

遊戲應提供三種主要體驗：
- **成長快感**：角色在一場遊戲中逐漸變強。
- **構築快感**：透過武器、被動能力、特殊技能與屬性升級形成不同組合。
- **生存壓力**：敵人數量與強度隨時間提高，玩家必須持續移動並閃避。

## 3. 玩家角色

### 3.1 基本規則

- 固定一名職業角色。
- 角色外觀、服裝與武器由 Codex 設計。
- 玩家移動使用 WASD。
- 支援斜向移動，移動向量必須正規化。
- 移動採立即達到指定速度的方式，放開按鍵立即停止。
- 玩家可以穿過敵人，但會受到接觸傷害。
- 玩家碰到競技場邊界時不能繼續前進。

### 3.2 玩家基礎屬性

玩家固定具有五項基礎屬性：

| 屬性 | 說明 |
|---|---|
| 最大生命值 | 玩家可承受的生命值上限 |
| 攻擊力 | 攻擊傷害計算基礎 |
| 攻擊速度 | 以倍率表示攻擊頻率 |
| 移動速度 | 玩家移動速度 |
| 防禦力 | 依防禦公式降低受到的傷害 |

初始數值由 Codex 設計並記錄，透過後續遊玩測試確認合理性。

局內升級與局外強化對相同屬性的加成直接相加。特殊技能及被動能力也可以影響上述屬性，但不得破壞既定數值計算規則。

### 3.3 生命與傷害

- 玩家具有生命值。
- 受到傷害時套用防禦力遞減公式。
- 每次受到傷害至少為 1。
- 所有敵人攻擊共用相同減傷公式。
- 所有傷害來源共用約 1 秒無敵時間。
- 無敵期間玩家角色閃爍。
- 生命恢復不得超過最大生命值。
- 不加入護盾系統。
- 不加入暴擊系統。
- 玩家受傷時 HUD 生命區域短暫閃爍。
- 生命值低於 30% 時，血條改變外觀並顯示警告效果。

防禦公式、攻擊速度倍率上限與移動速度上限由 Codex 設計及記錄，不預先指定具體數值。

## 4. 武器系統

### 4.1 基本規格

- 武器總數：5 種。
- 開始時 5 種武器全部開放。
- 每場遊戲開始前選擇一把初始武器。
- 初始武器占用最多 3 個武器欄位中的一格。
- 最多同時持有 3 種武器。
- 每種武器最高 5 級。
- 每種武器必須有明確攻擊定位，不能只有外觀或數值差異。
- 武器升級可以增加數值，也可以改變攻擊機制。
- 特定等級必須具有攻擊機制變化。

### 4.2 武器設計方向

Codex 設計五種不同武器，攻擊方式可包含：
- 直線投射物。
- 環繞攻擊。
- 範圍爆炸。
- 追蹤投射物。
- 其他符合核心規則的不同攻擊方式。

每種武器必須具備：
- 明確定位。
- 獨立攻擊範圍。
- 攻擊方式。
- 攻擊冷卻。
- 傷害與攻擊速度設定。
- 升級效果清單。
- 特定等級的機制變化。

### 4.3 攻擊規則

- 角色自動攻擊，不需要玩家按下攻擊鍵。
- 需要目標的武器選擇攻擊範圍內最近的敵人。
- 攻擊範圍內沒有敵人時不攻擊。
- 攻擊冷卻持續運作；冷卻完成但沒有目標時等待，有目標後立即攻擊。
- 每種武器有獨立攻擊計時器，可以同時運作。
- 不需要目標的武器依自身攻擊機制運作。
- 攻擊時鎖定敵人當下位置，不預測未來移動。

### 4.4 投射物規則

- 直線投射物預設只能命中一個敵人。
- 特定升級效果可以增加穿透能力。
- 每顆投射物對同一敵人最多造成一次傷害。
- 投射物達到穿透上限或飛行時間結束時消失。
- 投射物發射瞬間決定方向，之後沿直線飛行，不再修正方向。
- 不同武器可以有不同投射物速度、存在時間與最大飛行距離。
- 大量重複生成的投射物必須使用 Object Pooling。

## 5. 被動能力系統

### 5.1 基本規格

- 被動能力總數：5 種。
- 五種能力從遊戲開始就能透過升級取得。
- 最多持有 5 種被動能力。
- 被動能力取得後立即生效，不需要玩家額外操作。
- 每種被動能力具有獨立等級上限，由 Codex 設計。
- 能力不能只是單純更換數值，必須有不同功能。
- 允許持續生效與定時觸發效果。
- 部分能力升級必須有機制變化。
- 可以影響武器攻擊機制，但不得破壞既有規則。
- 可以強化五項基礎屬性，與獨立屬性升級疊加。

### 5.2 設計要求

Codex 必須設計五種不同功能的被動能力，並為每種能力定義：
- 能力定位。
- 取得後效果。
- 等級上限。
- 各級效果。
- 是否改變戰鬥機制。
- 與武器及特殊技能的搭配方式。

## 6. 特殊技能系統

### 6.1 基本規格

- 特殊技能總數：2 種。
- 一種為自動觸發攻擊技能。
- 一種為常駐輔助技能。
- 兩種技能都透過升級選項取得。
- 兩種技能可以同時持有。
- 各自占用獨立欄位。
- 具有等級上限，由 Codex 設計。
- 特定等級可以改變或增加技能機制。
- 只提供正面效果，不設計負面代價。
- 可以與其他能力自然搭配，不新增複雜組合系統。

### 6.2 自動觸發技能

- 具有獨立冷卻時間。
- 冷卻完成後自動觸發。
- 目標選擇與攻擊方式依技能自身機制決定。
- 允許範圍傷害與異常狀態。
- 可以攻擊普通敵人、精英與 Boss，除非技能本身有合理限制。
- 傷害計入玩家傷害、擊殺數與掉落判定。
- 是否受到玩家攻擊力影響由 Codex 設計並記錄。

### 6.3 常駐技能

- 取得後立即生效，持續至本場結束。
- 允許持續與週期性效果。
- 可以影響玩家五項基礎屬性。
- HUD 顯示圖示與等級，滑鼠移入顯示效果。

### 6.4 技能共同規則

- 技能冷卻與效果在暫停時停止。
- 恢復遊戲後繼續計算。
- 死亡或勝利時立即停止技能冷卻、觸發與效果。
- 清除技能相關投射物與特效。
- 可以同時傷害多個敵人，攻擊範圍與目標數量由 Codex 設計。
- 允許少量異常狀態，但不得引入複雜新系統。

## 7. 基礎屬性升級

五項基礎屬性各自具有獨立等級：
- 最大生命值。
- 攻擊力。
- 攻擊速度。
- 移動速度。
- 防禦力。

規則：
- 每項基礎屬性最高 5 級。
- 每級增幅由 Codex 設計。
- 基礎屬性升級不占用被動能力欄位。
- 與被動能力及局外強化加成疊加。
- 達到 5 級後從升級選項移除。
- HUD 顯示目前數值，不顯示等級。

## 8. 升級抽選規則

### 8.1 升級選項

- 升級時遊戲完全暫停。
- 顯示三個選項。
- 玩家透過滑鼠或數字鍵 1、2、3 選擇。
- 選擇完成後立即關閉升級畫面。
- 不支援方向鍵切換。
- 升級選項不足三個時，以特殊獎勵補足。

### 8.2 抽選順序

1. 優先從尚未取得的武器、被動能力、特殊技能抽選。
2. 這些尚未取得能力平等參與抽選。
3. 不足三個時，再從已取得且未滿級能力的升級效果中抽選；曾取得的效果仍可再次出現。
4. 五項基礎屬性升級與能力升級效果共用抽選池。
5. 每個可選擇的升級效果都是獨立抽選單位，機率相同。
6. 所有升級效果都可以重複取得，直到能力達到等級上限。
7. 同一輪可以出現同一能力的兩個不同升級效果。
8. 同一能力的兩個不同效果可以同時出現在同一輪。
9. 同一輪不得出現完全相同的升級效果。
10. 同一項基礎屬性在同一輪最多出現一次。

### 8.3 升級效果清單

- 每個能力預先設計固定升級效果清單。
- 抽選時從未滿級能力仍可取得的效果中選擇；曾取得效果不會被排除，同輪仍遵守去重規則。
- 同一效果可重複取得。
- 效果重複時的疊加方式由 Codex 依效果類型決定。
- 效果上限不得早於能力滿級。
- 所有能力滿級後，所有升級選項改為特殊獎勵。

### 8.4 特殊獎勵

- 選項不足三個時使用特殊獎勵補足。
- 所有能力滿級後，三個選項全部改為特殊獎勵。
- 特殊獎勵從所有可用獎勵中等機率抽選。
- 同一次升級允許相同特殊獎勵重複出現。
- 可以包含額外貨幣、生命恢復或其他立即生效效果。
- 不得新增永久能力或複雜新系統。

## 9. 敵人設計

### 9.1 普通敵人

共三種：

1. 近戰敵人。
2. 遠程敵人。
3. 自爆敵人。

三種敵人必須有不同戰鬥威脅與閃避方式。

#### 近戰敵人
- 朝玩家移動。
- 接觸玩家造成傷害。
- 受玩家無敵時間限制。

#### 遠程敵人
- 先瞄準玩家。
- 短暫預備後發射直線投射物。
- 發射時鎖定玩家當下位置。
- 不追蹤玩家後續移動。

#### 自爆敵人
- 靠近玩家後短暫蓄力。
- 顯示爆炸範圍。
- 蓄力完成後自爆。

### 9.2 敵人共同規則

- 依敵人定位設定不同移動速度與生命值。
- 受傷時必須有明確視覺反應。
- 敵人受傷時短暫閃白或改變顏色。
- 頭上顯示生命條。
- 生命條初始隱藏，第一次受傷後顯示，直到死亡都不關閉。
- 敵人互相推擠，避免完全重疊。
- 敵人可以有簡單額外行為，但不得增加複雜 AI。
- 隨難度階段調整行為，不增加全新敵人種類。
- 敵人不得離開競技場，超出範圍立即回收，不產生掉落物。

### 9.3 精英敵人

- 第 3 分鐘出現。
- 從競技場邊緣生成。
- 是強化版普通敵人。
- 具有較高生命值、攻擊力與移動速度。
- 有獨立外觀與生命條呈現。
- 是否有獨立攻擊特徵由 Codex 設計，但必須有足夠辨識度。
- 保證掉落較大量貨幣。

### 9.4 Boss

- 第 7 分鐘出現。
- 從競技場邊緣生成。
- 有獨立外觀。
- HUD 固定位置顯示 Boss 名稱與生命條。
- 多種攻擊模式，但不需要複雜階段變化。
- 依冷卻時間隨機使用近戰與遠程投射物攻擊。
- 所有攻擊都必須有明確預警。
- 出場顯示名稱，播放音效或簡短動畫。
- 被擊敗時顯示提示並播放音效。
- Boss 存活期間降低普通敵人生成頻率。
- Boss 死亡後恢復一般敵人生成頻率。
- Boss 存活期間一般敵人仍然生成。
- 保證掉落大量貨幣與經驗值。
- Boss 數值應盡量設計成遊戲結束前可以擊敗。

## 10. 難度與生成階段

### 10.1 五個階段

| 階段 | 時間 |
|---|---|
| 第一階段 | 0～2 分鐘 |
| 第二階段 | 2～4 分鐘 |
| 第三階段 | 4～6 分鐘 |
| 第四階段 | 6～8 分鐘 |
| 第五階段 | 8～10 分鐘 |

### 10.2 難度成長

每兩分鐘提升一次難度。

各階段可以調整：
- 敵人種類。
- 敵人生成數量。
- 敵人生成間隔。
- 敵人生命值。
- 敵人攻擊力。
- 敵人移動速度。
- 敵人行為。

Codex 自行設計具體數值與生成比例，必須確保難度逐步提高且仍可通關。

階段切換時：
- 只影響新生成敵人。
- 場上既有敵人維持原本數值。
- 顯示簡短階段切換提示。
- 播放對應音效。
- HUD 持續顯示倒數時間，不需要持續顯示階段名稱。

### 10.3 精英與 Boss

- 精英：第 3 分鐘。
- Boss：第 7 分鐘。
- 精英與 Boss 不計入一般敵人同時存在數量上限。
- 出現時不清除場上普通敵人，只降低後續生成頻率。

### 10.4 敵人數量上限

- 一般敵人達到同時存在數量上限時停止生成。
- 場上數量下降後恢復生成。
- 不向玩家顯示數量上限提示。
- Codex 設計合理上限與生成策略，不得造成集中爆發。

## 11. 掉落物與經濟

### 11.1 經驗寶石

- 每隻敵人固定掉落一顆經驗寶石。
- 經驗值依敵人種類決定。
- 不同經驗值寶石使用相同外觀。
- 拾取後立即更新經驗值與 HUD。
- 不顯示獲得經驗的浮動數字。

### 11.2 貨幣

- 普通敵人有不同隨機掉落機率。
- 精英與 Boss 保證掉落較大量貨幣。
- 貨幣數量由 Codex 設計。
- 拾取時顯示獲得數量浮動文字。
- 立即更新持有總額。
- 本場未拾取貨幣在死亡或勝利時全部清除。
- 未拾取貨幣死亡後消失，不計入結算。

### 11.3 磁吸與拾取

- 經驗寶石與貨幣共用相同磁吸範圍。
- 進入範圍後立即朝玩家移動。
- 使用固定速度朝玩家移動。
- 碰到玩家後自動拾取。
- 磁吸時不增加特殊效果。
- 掉落物不需要閃爍、旋轉或浮動動畫。
- 同時拾取多個貨幣時的計算與顯示由 Codex 決定，但總額必須正確。
- 掉落物存在時間與數量必須受到管理，不得無限制累積。
- 大量掉落物使用 Object Pooling。
- 場上掉落物過多時，Codex 可合併或限制，但經驗與貨幣總額必須正確。

### 11.4 經驗升級

- 升級所需經驗值逐次增加。
- 經驗成長曲線由 Codex 設計。
- 前、中、後期應有不同成長速度。
- 經驗溢出保留。
- 升級後若經驗仍足夠，完成目前選擇後立即進入下一次升級。
- 不會同時開啟多個升級畫面。

## 12. 局外強化

五種強化：
1. 最大生命值。
2. 攻擊力。
3. 攻擊速度。
4. 移動速度。
5. 防禦力。

規則：
- 五種強化一開始全部開放。
- 每種有等級上限。
- 每次購買只提升一級，可重複點擊。
- 貨幣足夠時直接購買。
- 貨幣不足時購買按鈕停用。
- 達最高等級顯示 MAX，購買按鈕停用。
- 每次購買後立即更新屬性與貨幣。
- 局外強化的加成直接加到初始屬性。
- 購買後立即存檔。
- 免費重置全部強化，並全額退還已花費貨幣。
- 重置前顯示確認視窗，說明會全額退還貨幣。
- 約 10～15 場遊戲可將全部強化升滿。
- 強化上限、價格與增幅由 Codex 設計並透過後續測試調整。
- 只能從主選單進入局外強化畫面，不可在戰鬥中開啟。

## 13. 競技場與鏡頭

- 固定大小封閉競技場。
- 競技場形狀與尺寸由 Codex 設計。
- 必須提供足夠空間讓玩家閃避敵人。
- 玩家每場固定在競技場正中央生成。
- 鏡頭跟隨玩家。
- 競技場範圍大於畫面，玩家只能看到局部區域。
- 鏡頭受到競技場邊界限制，不會看到場地外區域。
- 玩家碰到邊界時無法繼續前進。
- 敵人從戰場四周邊緣隨機生成。
- 敵人只能在玩家目前畫面以外生成。
- 玩家靠近邊界時，優先尋找距離玩家較遠且位於畫面外的邊緣位置。
- 找不到合適位置時才允許畫面內生成。
- 生成位置不得直接位於玩家碰撞範圍內。
- 敵人生成前顯示短暫視覺提示。
- 敵人卡住時需要簡單偵測與恢復機制。

## 14. 勝敗規則

- 戰鬥開始前有短暫開場倒數。
- 開場倒數結束後才開始 10 分鐘計時。
- 存活 10 分鐘立即勝利。
- 玩家生命值歸零立即失敗。
- 死亡與倒數結束依事件實際發生順序判定，先發生者優先。
- 勝利時立即停止所有戰鬥邏輯。
- 死亡時播放簡短死亡動畫，再進入結算。
- 勝利與失敗播放不同音效。
- 勝利與失敗視覺呈現由 Codex 設計，但必須明確區分。
- Boss 擊殺額外提供大量貨幣與經驗值。
- Boss 不必擊敗才能勝利，但應盡量讓玩家在時間結束前有機會擊敗 Boss。
