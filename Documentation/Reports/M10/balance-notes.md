# 平衡樣本與方法

M10BalanceProbe 使用 1/30 秒固定步長執行真實 BattleWorld、物理掃掠、掉落及升級選項。普通起始屬性、沒有局外強化，不贈送武器、生命、經驗或貨幣；只從抽到的選項挑選，優先初始武器、回血、攻擊／攻速。八方向移動路線與危險迴避，接近安全掉落。敵人亂數沿用 BattleConfig，升級種子每樣本明確記錄。JSON 包含每30秒血量、擊殺、等級、敵人及收益和所有選擇。

這是可重現的加速邏輯模擬，不能作為正常10分鐘實玩、輸入操作或FPS證據。M11另做正常時間回歸。單一策略／種子樣本只能支持可完成與初始經濟估算，不代表所有玩家的勝率或所有抽選均衡。

Orbit 的站立貼身死角仍是定位差異，但正常移動可以擊殺、拾取與完成一場，BAL-001不再以站立案例判定不可用。固定五階段、精英180秒、Boss420秒規則沒有因平衡測試改動。

Pulse（seed46）亦600秒勝利，630擊殺、27級、497貨幣，精英／Boss皆擊敗。五樣本平均475.4；原全滿750只需約1.58次勝利，明顯偏短。

最終將基價從10改為75，各屬性五級價格75／150／225／300／375，每項1125、五項共5625。全勝按樣本約11.83場；以80%勝利及20%沿用M7實際死亡34貨幣的敏感度估算，每場387.12、約14.53場。兩者落在約10～15場目標。候選基價80需6000，混合估算15.50場，故最後微調75。80%勝率是明示的假設，不是玩家群體測得勝率；大量早死仍需更多場，隨永久強化增加的收益亦未納入，後續需真人資料校準。

價格由FlowConfig.metaBasePrice設定；存檔v3新增實際支付帳本。v1/v2的歷史購買按當時基價10遷移；新購買累積當次成本，改價後退款不重算歷史。所有等級與貨幣保持交易式提交，故障不改記憶體或主檔。
