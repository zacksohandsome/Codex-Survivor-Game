# M6 全部武器與成長內容

日期：2026-11-04。Windows Build 依使用者要求暫緩。

## 完成內容

- 五把武器全部可選為初始武器：直線、環繞、延遲爆炸、追蹤與擴張波。每把上限5級、最多持有3把、獨立冷卻與加成；所有武器在第3級有機制變化。
- 五種功能不同的被動：定時恢復、共享磁吸、命中連鎖、受傷反擊、移動傷害區。
- 兩種可同持技能：Starfall 自動攻擊、Sanctuary 常駐防禦／週期推離；不加入護盾或暴擊。
- 五項局內屬性各5級、不占被動格，與五種永久強化直接相加；永久購買／MAX／退款沿用 M4。
- 靜態內容新增為 ScriptableObject；新增32個有界區域效果池，彈體仍使用既有有界池。所有攻擊共用傷害顯示、死亡、擊殺與掉落入口。
- HUD 預留兩行構築文字、結算增加構築顯示高度；正式圖示、Tooltip、雙語及介面視覺仍在 M8～M9。
- 完整定位、數值、等級門檻與效果疊加見 [CONTENT_MATRIX.md](../../CONTENT_MATRIX.md)。

## 驗證與修正

- Edit Mode **48/48**、0 failed：原44項回歸，加上內容數量、武器效果隔離、三武器上限、技能同持及全滿級獎勵驗證。見 `editmode-results.json`。
- Play Mode **26/26**、0 failed：原21項回歸，加上每把初始武器的實際擊殺／掉落、獨立冷卻／Lv3雙發、追蹤方向與直線固定方向、連鎖／反擊／移動觸發、兩技能與恢復／磁吸。見 `playmode-results.json`。
- 初次新增整合測試缺少 yield，出現 CS0161；補上後編譯成功。最終 Console ground truth 0 error、0 warning、compilationFailed=false。
- `weapon-selection.png` 為可選五武器畫面。`content-fixture.png` 為三武器＋五被動＋兩技能的隔離測試構築中的升級畫面；能力直接設定到Lv3，不宣稱是在正常一場中取得。`fixture-state.json` 為截圖前的運行狀態，已發生9次擊殺；畫面隨後進入下一次升級，並非同幀擷取。
- 原地不動的初始 Orbit 試玩在19秒死亡且未取得擊殺：此武器需要移動讓敵人通過環繞路徑，不能把站立生存當成平衡驗收。保留為 M10 比較構築與初始體驗的觀察；自動整合測試已驗證它可實際命中、擊殺及掉落。
- M5 影片另以 MP4 movie header 確認可辨識時長 **628.49秒**、70,589,476 bytes；見 M5/media-verification.json。影片時間戳與實玩取樣不完全一致，以 M5 的真實時間／戰鬥時間紀錄驗證600秒遊玩，不把編碼時長當作精確遊戲計時。

## 限制與後續

- 本階段未聲稱全部構築已平衡、能正常存活10分鐘或完成效能最佳化。M5完整600秒實玩是擴充前的 MVP；M6新增內容有上述功能回歸與隔離展示。
- 使用者回報的戰鬥卡頓仍待 Profiler 診斷；PERF-001 保留，正式1080p 60FPS驗收在 M10。
- 沿用幾何佔位圖片；尚未進入 M9，因此本次沒有需要生成的正式圖片或新增音效／BGM。
- M7 前的 D03 是既有核心規格疑義：精英是否也應降低普通敵人生成頻率，以及何時恢復。依 EXECUTION_PLAN 與 CODEX_WORKFLOW §5.2，等待使用者確認，尚未實作 M7；不因使用者暫時離線自行決定此規則。
